# Biodiversidad de Córdoba

Sitio educativo en HTML, CSS y JavaScript. No requiere instalar dependencias.

## Abrir el sitio

Desde esta carpeta, ejecutá:

```powershell
python -m http.server 8000
```

Luego abrí `http://127.0.0.1:8000` en el navegador.

## Catálogo y fotografías

- `species-data.js` contiene los registros del catálogo y los metadatos de imágenes.
- `script.js` implementa el buscador, filtros, orden, fichas y navegación.
- `imagenes/` guarda copias locales de fotografías, organizadas por grupo.
- Cada crédito enlaza a su archivo original y a la licencia. Las imágenes sin una coincidencia verificable permanecen señaladas como pendientes..

## Prevención de incendios

- `incendios.html`, `incendios.css` y `incendios.js` implementan la página de prevención para el Valle de Punilla.
- `datos-incendios.js` centraliza localidades y enlaces a fuentes oficiales.
- Los mapas IDECOR se cargan desde sus visores oficiales. La hora mostrada corresponde a la solicitud del visor, no a la actualización de los datos.
- No se simulan valores meteorológicos ni alertas: si no hay un feed verificable, se indica que la información no está disponible y se enlazan las fuentes oficiales.
